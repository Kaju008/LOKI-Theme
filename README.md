# Kaju Soni — Master of Timeline

A 3D scroll-driven portfolio: a thought becomes a particle brain, bursts into a universe,
and the camera flies to the Timekeeper on his throne above a Bifrost-like bridge of editing timelines.

- `index.html`, `css/main.css` — page + styling
- `src/` — source (three.js scenes, scroll story, UI). Edit `src/config.js` for text, videos, tools and contact.
- `js/app.js` — built bundle (run `npm install` once, then `npm run build`)
- `assets/` — fonts, textures, figure model, thumbnails, résumé
- `games.html`, `lab.html` — extra pages (coming soon)

Preview locally: `npm run serve` → http://localhost:8000
